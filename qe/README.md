# qe/: Quantum Edge canonical workspace

Governed by `quantum-edge-governance/QEGP_MASTER_PROMPT_v4.md`. **Start with `PROJECT_STATE.json`.**

| Path | What it holds |
|---|---|
| `PROJECT_STATE.json` | Current phase, open defects, pending decisions |
| `DECISIONS.md` / `DECISIONS_PENDING.md` | Decision log and the A2 decisions waiting on a human |
| `audit/PHASE_0_FORENSIC_REPORT.md` | Phase 0 findings and the answer to "what does Quantum Edge actually do" |
| `audit/PHASE_1_DIVERGENCE_REPORT.md`, `audit/GODS_PLAN_RULE_DIVERGENCE_MATRIX.csv` | Phase 1: how every implementation defines each God's Plan concept |
| `audit/DEFECT_REGISTER.csv` | 45 defects with location, mechanism, reachability, evidence (generated by `tools/defects.py`) |
| `audit/REPOSITORY_INVENTORY.csv` | Every file in the two legacy subtrees, classified (generated) |
| `audit/*.md` | Baseline, dependency graph, order-path map, data map, threat models, security baseline |
| `evidence/EVIDENCE_MATURITY_MATRIX.csv` | Evidence level per capability |
| `tests/regression/legacy/` | 32 strict-xfail reproductions of legacy defects |
| `tests/boundary/` | Quarantine: canonical code may not import legacy code, broker SDKs or LLM SDKs |
| `core/` | Canonical primitives with no strategy semantics: ticks, instrument risk and net R, clock, canonical hashing, bar events, mode firewall (ADR-0004) |
| `config/instruments.json` | Instrument specs, all `verified: false` until checked against CME |
| `spec/INVARIANT_TRACEABILITY.csv` | Which test proves which invariant |
| `tools/` | Scanner, import sweep, inventory merge, defect register, `run_phase0.sh` |

```bash
bash qe/tools/run_phase0.sh     # rebuild generated artifacts and run the reproductions
```

The legacy subtrees (`QuantumEdge/`, `quantum-edge-terminal/`) are read-only evidence. Nothing in `qe/` may import from them except the loaders in `tests/regression/legacy/`.
